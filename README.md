# KVNLibrary

## YouTube Importer (Adobe Premiere Pro)

Extensão CEP para o Adobe Premiere Pro que importa trechos de vídeos do
YouTube direto para o Project Panel ou para a Timeline. Código-fonte
completo, documentação de instalação/uso e solução de problemas em
[`YouTubeImporter/README.md`](YouTubeImporter/README.md).
